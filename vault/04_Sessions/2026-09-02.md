# 2026-09-02 — Experimental detector Product 1

## Scope

Implemented the first bounded slice of the accepted detector-first
architecture. This is an experimental current-fuvpy Product 1, not a selected
publication preprocessing configuration.

## Result

- Added `icbuilder/fuvdetector.py` for WIC-led time support, Modified-Apex WIC
  geometry, independent SI12/SI13 footprint coregistration, support fields,
  diagnostics, provenance, and NetCDF serialization.
- Added `scripts/pipeline/make_fuv_detector_orbit_files.py` for WIC-led orbit
  discovery, exact configuration/source/implementation restart identity, and
  atomic publication.
- Extended the detector-coregistration prototype to handle empty diagnostics
  safely and accept an explicit coverage threshold.
- Added focused matching, coregistration, schema, provenance, source-change,
  and restart tests.

The final isolated run used the tracked 20-frame orbit-0085 excerpt. It wrote
an 18.94-MB `(20, 256, 256)` product in 142.69 seconds. WIC, SI12, and SI13
finite support was 33.42%, 32.33%, and 31.31%. Both SI channels matched every
WIC frame within zero to one second. Stored source hashes reproduced and the
repeat command skipped the valid file.

Verification: nine focused detector Product-1/coregistration tests pass; the
broader related subset has 31 passes. The full suite has 83 passes and four
pre-existing failures from the 46-by-46 active grid versus 36-by-36 tests and
the bundled Zhang--Paxton lookup.

## Boundary and next action

The tracked orbit is only a partial excerpt, so the run is not complete-orbit
or publication validation. Coregistration is also too slow for a corpus.
Profile and optimize the per-frame WIC transform and SI overlap construction,
then validate one complete orbit before moving detector Product 2.

Detector radiometry, detector-noise/correlation representation, SI12
map-versus-infer ordering, and final preprocessing/frame support remain open
scientific decisions.
