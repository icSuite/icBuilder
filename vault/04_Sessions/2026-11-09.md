# Pre-proton WIC carried into precipitation CS

Last reviewed: 2026-11-09

Commit `e4c5479` conditionally carries detector Product-2 `wic_smoothed` and
`dwic_smoothed` through the 46-by-46 precipitation-CS reduction. Counts use
the same overlap-area mean and common method support as corrected WIC;
uncertainty uses the existing squared normalized overlap-weight propagation.
The pair remains optional, so unsmoothed detector products and older CS files
retain their existing contract. Restart validation rebuilds a CS file when its
smoothed detector source contains the pair but the CS output does not.

The fields support a controlled icAnalyzer comparison of proton-corrected and
pre-proton WIC morphology. Pre-proton counts still contain proton emissions
and must not be passed directly to electron-conductance conversion.

Verification: 61 relevant detector Product-2, Hardy and detector-CS tests pass
with icReader commit `587c538` on `PYTHONPATH`.

Portfolio impact: Central update needed: No.
